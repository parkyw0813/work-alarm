# 출퇴근 알리미

컴퓨터를 처음 켠 시각을 기준으로 퇴근 시간을 알려 주는 작은 프로그램 (윈도우 전용).

- 켠 시각 + 9시간 = 퇴근 (예: 09:00에 켜면 18:00)
- 점심 12:00, 10분 전(11:50)에 알림
- 퇴근 10분 전, 퇴근 시각에 알림
- 작업표시줄 오른쪽 아래 파란 시계 아이콘
  - 마우스를 올리면 남은 시간
  - 더블클릭하면 알림으로 남은 시간
  - 오른쪽 클릭하면 출근·점심 알림·퇴근 시각, 종료
  - 오른쪽 클릭 → "출근 시각 고치기..."로 오늘 출근 시각을 직접 바꿀 수 있다(그날만 적용)
  - 고친 뒤엔 "켠 시각으로 되돌리기"로 자동 값으로 돌아간다

## 설치 / 제거
- `설치.bat` 더블클릭 → 컴퓨터 켤 때마다 자동 실행 + 지금 바로 실행
- `제거.bat` 더블클릭 → 자동 실행 해제 + 종료

알림은 윈도우 기본 알림이 아니라 알리미가 직접 그리는 카드 창이다(윈도우 알림은 이런 프로그램에서 사진·아이콘을 안 그려 줘서 바꿈). 오른쪽 아래에 떠올랐다가 15초 뒤 사라지고, 마우스를 올려 두면 유지, 클릭하면 닫힌다. 윈도우 어두운 테마면 어둡게 나온다. 시작 메뉴에도 "출퇴근 알리미" 바로가기를 만들어 둔다(눌러서 다시 켤 수 있음).

## 알림 사진
`assets` 폴더에서 파일 이름 앞부분으로 골라 무작위로 하나씩 띄운다(jpg·png·gif·bmp).
- `출근…` 알리미가 켜질 때
- `점심…` 점심 10분 전
- `퇴근…` 퇴근 10분 전, 퇴근 시각
사진을 더 넣거나 빼려면 이 규칙대로 이름만 맞춰 폴더에 넣으면 된다(다시 켤 필요 없음).

## 다른 사람에게 주기
`make-package.ps1`을 돌리면 `dist\출퇴근알리미.zip`이 만들어진다(알리미를 고친 뒤 다시 돌리면 최신으로).
받은 사람은 압축을 풀고 `설치.bat` → `%LOCALAPPDATA%\WorkAlarm\app`에 복사·자동 실행 등록. 배포용 설치·제거·사용법 원본은 `package\`.

## 화면 모드·마우스 올림 카드
- 트레이 우클릭 → 화면 모드(시스템 따라가기·라이트·다크). 고른 값은 `%LOCALAPPDATA%\WorkAlarm\theme.txt`
- 아이콘에 마우스를 올리면 윈도우 기본 말풍선 대신 큰 안내 카드(남은 시간 + 퇴근·출근 시각)

## 시간 바꾸기
`work-alarm.ps1` 맨 위 "설정" 부분 숫자만 고치면 된다.

## "켠 시각"을 잡는 방법
오늘 새벽 5시 이후 기록 중 가장 이른 것:
부팅 시각, 절전·빠른 시작에서 깨어난 시각, 알리미가 처음 뜬 시각.
(윈도우 "빠른 시작" 때문에 끈 것이 사실상 절전이어도 아침에 켠 시각을 잡는다.)

기록 위치: `%LOCALAPPDATA%\WorkAlarm\` (start.txt, error.log)
